# AR Enterprise / AR Energy Services

This repo holds the live public website for **arenergyservices.in** (`index.html`, `assets/`).

Before doing any work on the wider platform (public Impact page, Ops workspace, data server, field
tools, Report Studio), read **`docs/PLATFORM_RULES.md`**. It defines the domain split, the naming
scheme (old KISEM project names such as FOX, Jet EFF, A-CMP, PostMan must not be used), the
system-generated industry tags (no client names on public pages), the shared data flow and the
security roles. Keep that file up to date whenever a decision changes.
